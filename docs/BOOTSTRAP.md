# FieldTrust Bootstrap

The repository now contains product docs and the first Flutter source shell, but native platform folders should be generated by Flutter rather than hand-written.

## 1. Clone

```bash
git clone git@github.com:rwecho/FieldTrust.git
cd FieldTrust
```

## 2. Verify Flutter / Dart

Current `shadcn_ui 0.56.3` requires Dart 3.11+.

```bash
flutter --version
dart --version
```

Use a Flutter SDK that bundles Dart 3.11 or newer.

## 3. Generate native platform folders

From the repository root:

```bash
flutter create . --platforms=ios,android --org com.rwecho --project-name fieldtrust
```

Important: review generated files before committing so `pubspec.yaml`, `README.md`, `analysis_options.yaml`, and existing `lib/` sources are not unintentionally overwritten.

A safer workflow is to run the command in a temporary directory and copy only `android/` and `ios/` into this repository if your Flutter version attempts to rewrite existing project files.

## 4. Install packages

```bash
flutter pub get
```

## 5. Run static checks

```bash
flutter analyze
flutter test
```

## 6. Firebase setup

Do this after the local-first capture foundation is working.

Recommended later flow:

```bash
dart pub global activate flutterfire_cli
flutterfire configure
```

Configure Android and iOS apps for the FieldTrust Firebase project.

Do not commit service-account secrets or unrelated private credentials.

## 7. First implementation target

Start with Milestones 0–2 from `docs/MVP.md`:

1. theme / navigation foundation
2. Drift local database
3. app-managed media paths
4. local project CRUD
5. camera capture
6. location accuracy
7. atomic local save
8. SHA-256
9. durable sync-job row

Do not start Firebase upload until `Saved locally` is reliable under offline and process-kill tests.

## 8. Definition of the first vertical slice

The first meaningful demo should be:

```text
Create Project
  → Open Project
  → Take Before Photo
  → Photo safely saved locally
  → GPS accuracy visible
  → Kill/restart app
  → Photo is still present in project gallery
```

That vertical slice matters more than adding extra screens.
